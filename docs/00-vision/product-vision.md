# Product Vision — Apps Marketing

## Visión

Apps Marketing / Yoryi AI Studio ayuda a negocios de servicios, profesionales independientes y pequeñas empresas a convertir su presencia digital en conversaciones comerciales reales, leads calificados y oportunidades de venta.

El proyecto inicia con una landing comercial de alta conversión y evoluciona por fases hacia sistemas de captación, dashboard interno, automatización comercial e inteligencia artificial aplicada al proceso de ventas.

## Problema

Muchos negocios tienen presencia digital débil o poco efectiva:

- No comunican claramente qué venden.
- Tienen mensajes comerciales genéricos.
- No capturan leads de forma ordenada.
- Dependen solo de recomendaciones o redes sociales.
- No tienen una landing optimizada para conversión.
- No tienen seguimiento estructurado de prospectos.
- No saben cómo aplicar IA de forma práctica a su negocio.

El resultado es que pierden oportunidades comerciales aunque tengan buenos servicios.

## Solución

Apps Marketing / Yoryi AI Studio ofrecerá activos digitales orientados a conversión, comenzando por una landing profesional que explique la oferta, genere confianza y facilite el contacto mediante formulario y WhatsApp manual.

La solución se desarrollará por fases:

### Fase 1 — Landing comercial

Incluye:

- Home / landing principal.
- Hero comercial.
- Propuesta de valor.
- Servicios.
- Casos de uso.
- Beneficios.
- Proceso de trabajo.
- CTA a WhatsApp manual.
- Formulario de contacto.
- SEO básico.
- Diseño responsive.

### Fase 2 — Captura básica de leads

Incluye:

- Formulario más estructurado.
- Registro básico de prospectos.
- Notificaciones.
- Preparación para backend futuro.

### Fase 3 — Backend / Dashboard

Incluye:

- Gestión interna de leads.
- Estados de seguimiento.
- Historial básico.
- Panel administrativo.

### Fase 4 — AI Lead Assistant

Incluye:

- Asistente inteligente para captar leads.
- Clasificación de intención.
- Resumen comercial.
- Lead scoring.
- Integración futura con WhatsApp Cloud API.
- Ollama local como proveedor IA inicial.
- OpenAI API como proveedor opcional futuro.

## Criterio rector

Primero se valida la oferta, el mensaje y la conversión con un flujo manual.

Después se automatiza.

El proyecto no debe depender de IA, WhatsApp Cloud API, backend complejo o dashboard completo en la Fase 1.

## Propuesta de valor

Apps Marketing / Yoryi AI Studio no construye solo páginas bonitas.

Construye sistemas digitales progresivos para ayudar a negocios a:

- Explicar mejor su oferta.
- Captar más prospectos.
- Mejorar su conversión.
- Automatizar procesos comerciales.
- Prepararse para integrar IA de forma útil y controlada.

## Diferenciador

El diferencial del proyecto es combinar:

- Desarrollo web moderno.
- Estrategia comercial.
- Marketing digital.
- SEO básico.
- Automatización.
- Inteligencia artificial aplicada a ventas.

La visión es pasar de una landing comercial a una plataforma inteligente de captación y gestión de oportunidades.

## Qué NO es el producto en Fase 1

En Fase 1, el producto no es:

- Un chatbot inteligente.
- Un CRM avanzado.
- Un dashboard completo.
- Una plataforma de campañas.
- Un sistema con WhatsApp Cloud API.
- Un producto dependiente de OpenAI API u Ollama.
- Un sistema de pagos.

## Visión a largo plazo

Convertir Apps Marketing / Yoryi AI Studio en una plataforma modular donde cada negocio pueda tener:

- Landing comercial.
- Captura de leads.
- Dashboard interno.
- Automatizaciones.
- Asistente IA.
- Análisis de oportunidades.
- Herramientas de marketing y conversión.
