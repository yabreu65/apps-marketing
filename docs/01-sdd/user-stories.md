# User Stories — Apps Marketing / Yoryi AI Studio

## 1. Purpose

Este documento define las historias de usuario del proyecto `apps-marketing`, iniciando con la Fase 1: landing comercial orientada a conversión.

Las historias deben mantenerse alineadas con:

- `AGENTS.md`
- `docs/01-sdd/sdd-index.md`
- `docs/01-sdd/prd.md`
- `docs/01-sdd/scope.md`
- `docs/01-sdd/acceptance-criteria.md`

## 2. Scope Context

La Fase 1 se enfoca en construir una landing comercial para Apps Marketing / Yoryi AI Studio.

La Fase 1 incluye:

- Landing comercial.
- Hero claro.
- Propuesta de valor.
- Servicios.
- Casos de uso.
- Beneficios.
- Proceso de trabajo.
- CTA a WhatsApp manual.
- Formulario de contacto.
- SEO básico.
- Diseño responsive.

La Fase 1 no incluye:

- AI Lead Assistant.
- WhatsApp Cloud API.
- OpenAI API.
- Ollama.
- Lead scoring automático.
- Dashboard completo.
- CRM avanzado.
- Automatizaciones avanzadas.
- Pagos.

## 3. Actors

### Visitor

Persona que llega a la landing y quiere entender qué ofrece Apps Marketing / Yoryi AI Studio.

### Prospect

Visitante con intención comercial que puede contactar por WhatsApp o formulario.

### Business Owner

Yoryi / Apps Marketing, quien necesita presentar servicios, captar leads y validar la oferta.

### Future Admin

Usuario futuro que podrá gestionar leads en un dashboard cuando exista backend.

### Future AI Assistant

Módulo futuro que ayudará a calificar leads, resumir conversaciones y automatizar parte del proceso comercial.

## Traceability Rule

Cada historia de Fase 1 debe tener al menos un criterio de aceptación relacionado.

Las historias futuras deben mantenerse documentadas, pero no deben interpretarse como autorización para implementar módulos fuera de Fase 1.

## Final Statement

Las historias activas de Fase 1 están orientadas exclusivamente a construir una landing comercial clara, responsive, con SEO básico, CTA a WhatsApp manual y formulario de contacto.

AI Lead Assistant, backend, dashboard, WhatsApp Cloud API, Ollama, OpenAI API y automatizaciones avanzadas quedan documentados como evolución futura.
