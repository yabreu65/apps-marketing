# Phase 3 — Project Types / Portfolio Direction

## Status

Local stable update.

## Summary

Se agregó una sección de tipos de proyectos para reforzar que Apps Marketing / Yoryi AI Studio puede construir soluciones digitales desde landing pages hasta sistemas web, dashboards y MVP SaaS.

## What Changed

- Se creó data para tipos de proyectos.
- Se creó `ProjectTypesSection`.
- Se agregó `ProjectTypeItem` a los tipos del sitio.
- Se integró la sección después de servicios.
- Se diferenciaron estados: Disponible ahora, Proyecto a medida y Fase avanzada.
- Se mejoró la escaneabilidad mobile de las cards.
- Se evitó presentar clientes ficticios o casos reales inexistentes.

## Project Types Included

- Landing comercial.
- Sitio web profesional.
- Sistema web a medida.
- Dashboard / panel interno.
- MVP SaaS.
- Automatización comercial.
- IA aplicada al negocio.
- SEO / marketing digital inicial.

## Does Not Include

- AI Lead Assistant activo.
- WhatsApp Cloud API.
- OpenAI/Ollama.
- Backend.
- Dashboard real.
- Database.
- Pagos.
- Automatizaciones reales.
- Deploy.

## Validation

- `npm run lint`: OK
- `npm run build`: OK

## Notes

La sección funciona como dirección comercial y ejemplos de soluciones posibles, no como portfolio de clientes reales.
